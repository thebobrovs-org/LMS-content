**Claim.** Google renamed Vertex AI Search to Agent Search on 22 April 2026.

**Limits.** At the rename the console still showed "Vertex AI Search and AI Applications" and the APIs kept their Discovery Engine endpoints, so the old name persists in code and screenshots. The same product was earlier called Vertex AI Agent Builder (renamed AI Applications in April 2025) and AI Applications (renamed Vertex AI Search in October 2025); that chain is about this search product, not Agent Platform.
