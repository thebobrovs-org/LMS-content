# 3.5 Tools and integrations through MCP

**Topic id:** `agentic-ai/mcp-tools-and-integrations` · **Level:** 300 · **Difficulty:** advanced · **Est:** 25 min
**Track:** S3 Custom agents · **Exam objective:** 3.2 · **Persona:** `personas/agentic-ai.md`
**Status:** plan-approved

## Why / What / How
- **Why:** Agents earn their keep by acting on enterprise systems. The exam asks which integration path fits: a Google-managed MCP server, MCP Toolbox for Databases, or a custom MCP server.
- **What:** Google Cloud MCP servers (managed, remote), MCP Toolbox for Databases (Cloud SQL, BigQuery and more), custom MCP servers for internal APIs, and registering them in Agent Registry.
- **How:** Give the 3.2 support agent three capabilities by three routes and compare who runs, secures and updates each. Show the registry entry that makes them discoverable.

## Learning objectives
After this topic the learner can (ids become the lesson's `objectives`):
- `choose-integration`: Choose a managed MCP server, MCP Toolbox or a custom MCP server for a system.
- `database-tools`: Expose safe, parameterised database queries with MCP Toolbox.
- `register-tools`: Register MCP servers in Agent Registry for discovery and governance.

## Must-learn (keep nothing else but this)
1. Use a Google-managed MCP server when one exists for the service.
2. Expose named, parameterised queries, never free-form SQL, to an agent.
3. Register what agents may use, so it can be found and governed.

## Key terms (glossary)
- `Google Cloud MCP servers`: Google-managed remote MCP servers for Google Cloud services.
- `MCP Toolbox for Databases`: Open-source MCP server for exposing database queries as tools.
- `Agent Registry`: Catalogue of agents, MCP servers and endpoints for discovery and governance.
