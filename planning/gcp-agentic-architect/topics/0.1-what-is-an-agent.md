# 0.1 What makes something an agent

**Topic id:** `agentic-ai/what-is-an-agent` · **Level:** 100 · **Difficulty:** beginner · **Est:** 15 min
**Track:** Core · **Exam objective:** none (assumed by every section) · **Persona:** `personas/agentic-ai.md`
**Status:** planned

## Why / What / How
- **Why:** Half the exam's scenarios turn on whether a task needs an agent at all. Teams that call every LLM feature an agent overbuild simple flows and underbuild the guardrails real agents need.
- **What:** An agent is a model plus instructions plus tools, running in a loop that decides its own next step toward a goal.
- **How:** Contrast three designs for the same task (a chatbot that answers, a fixed workflow that runs set steps, an agent that chooses steps) and place them on a determinism spectrum: more autonomy buys flexibility and costs predictability, testability and control.

## Learning objectives
After this topic the learner can (ids become the lesson's `objectives`):
- `define-agent`: Name the parts of an agent (model, instructions, tools, loop, state) and what each contributes.
- `agent-vs-workflow`: Classify a use case as a chatbot, a deterministic workflow or an agent, and justify the choice.
- `autonomy-cost`: Explain what autonomy costs in predictability, evaluation effort and risk.

## Must-learn (keep nothing else but this)
1. An agent chooses its next action. A workflow follows steps you fixed in advance.
2. Prefer the least autonomy that solves the task. Add agency only where the path cannot be known ahead of time.
3. More autonomy means more need for evaluation, identity and guardrails (levels 400 and 500).

## Key terms (glossary)
- `agent`: A system in which a model decides, in a loop, which actions (tool calls) to take toward a goal.
- `workflow (deterministic)`: A fixed sequence of steps, possibly with model calls inside, whose order is set by the designer.
- `tool`: A function, API or service an agent can call to read data or take an action.
- `determinism spectrum`: The range from fully scripted flows to fully autonomous agents.
