# 3.4 RAG pipelines: retrieve, rerank and ground

**Topic id:** `agentic-ai/rag-pipelines` · **Level:** 300 · **Difficulty:** advanced · **Est:** 35 min
**Track:** S3 Custom agents · **Exam objective:** 3.2 · **Persona:** `personas/agentic-ai.md`
**Status:** planned

## Why / What / How
- **Why:** Retrieval decides answer quality more than the model does. 'Grounded but wrong' (the agent faithfully cites an outdated document) is a favourite exam trap.
- **What:** The RAG pipeline (ingest, chunk, embed, index, retrieve top-k, rerank, generate with citations), similarity scoring, and choosing RAG Engine, Agent Search or Vector Search/Agent Retrieval as the backend.
- **How:** A sim lets the learner tune chunk size, top-k and reranking over a small corpus with a stale and a current version of the same policy and watch which chunks reach the model. The lesson then maps needs to backends.

## Learning objectives
After this topic the learner can (ids become the lesson's `objectives`):
- `rag-stages`: Name the RAG stages and the decision at each.
- `tune-retrieval`: Predict how chunk size, top-k and reranking change what the model sees.
- `choose-backend`: Choose RAG Engine, Agent Search or Vector Search/Agent Retrieval for a scenario.
- `grounded-but-wrong`: Diagnose a grounded but wrong answer and fix it at the data layer.

## Must-learn (keep nothing else but this)
1. Retrieval quality caps answer quality.
2. Reranking reorders a wider candidate set by relevance; raising top-k alone adds noise.
3. A grounded answer can still be wrong if the source is stale. Fix freshness and metadata, not the prompt.
4. Out-of-the-box search (Agent Search) first; build your own pipeline only for control you need.

## Key terms (glossary)
- `RAG`: Retrieval-augmented generation: retrieve relevant content and give it to the model as context.
- `embedding`: A vector representing meaning, used for similarity search.
- `top-k`: How many retrieved chunks are passed on.
- `reranking`: Rescoring candidates with a stronger relevance model.
- `RAG Engine`: Agent Platform's managed RAG pipeline and corpus service.
