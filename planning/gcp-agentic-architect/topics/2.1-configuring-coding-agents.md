# 2.1 Configuring coding agents with MCP and skills

**Topic id:** `agentic-ai/configuring-coding-agents` · **Level:** 100 · **Difficulty:** beginner · **Est:** 25 min

## Why / What / How
- **Why:** A coding agent without context guesses; one with the wrong tools can do damage. Configuration decides both.
- **What:** Giving coding agents tools and know-how: MCP server configuration, skills with progressive disclosure, and running Claude Code on Google Cloud's Agent Platform and Antigravity against a Google Cloud project.
- **How:** Configure one MCP server (for example a database or Cloud API server) and one skill in a coding agent, then show how the agent loads only the skill's description until it needs the body.

## Learning objectives
After this topic the learner can (ids become the lesson's `objectives`):
- `configure-mcp`: Add an MCP server to a coding agent and scope the tools it exposes.
- `author-skill`: Structure a skill so the agent loads it only when relevant (progressive disclosure).
- `run-on-gcp`: Run Claude Code through Agent Platform or Antigravity in an enterprise Google Cloud project.

## Must-learn (keep nothing else but this)
1. MCP gives an agent tools; a skill gives it instructions and resources.
2. Skills load progressively: the description is always in context, the body only when triggered.
3. Expose the fewest tools the task needs; every tool is attack surface and prompt noise.

## Key terms (glossary)
- `MCP server`: A process that exposes tools, resources or prompts to an agent over the Model Context Protocol.
- `skill`: A folder of instructions and resources an agent loads on demand.
- `progressive disclosure`: Loading a skill's detail only when its description matches the task.
- `Antigravity`: Google's agentic development environment (app, CLI, SDK).
