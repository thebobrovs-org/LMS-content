# 1.3 Connecting enterprise data to Gemini Enterprise

**Topic id:** `agentic-ai/enterprise-data-gemini-enterprise` · **Level:** 200 · **Difficulty:** intermediate · **Est:** 25 min

## Why / What / How
- **Why:** An agent is only as useful as the data it can reach, and only as safe as the permissions it respects. Getting apps, data stores and connectors confused breaks both.
- **What:** Apps (engines), data stores (structured, unstructured, website) and connectors; blended search across stores; permission-aware results; bringing video, audio and images into the workflow; Agent Search as the retrieval layer.
- **How:** Wire one app to three data stores (a website, a Drive connector, a BigQuery table) and follow a query through blended search, showing where user permissions filter results.

## Must-learn (keep nothing else but this)
1. An app sits on one or more data stores; connectors keep third-party sources in sync.
2. Blended search queries several data stores at once.
3. Respect source ACLs: an agent must not widen what a user can read.

## Key terms (glossary)
- `data store`: An indexed collection of content an app searches.
- `connector`: A managed sync from a third-party source (Drive, Jira, Salesforce …) into a data store.
- `blended search`: One query across several data stores.
- `Agent Search`: Google's managed enterprise search and retrieval (formerly Vertex AI Search).
