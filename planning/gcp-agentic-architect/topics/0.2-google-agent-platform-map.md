## Why / What / How
- **Why:** The products were renamed in 2025 and 2026, so docs, blog posts and old practice questions disagree. A learner who cannot place a product cannot answer the scenario.
- **What:** One map of the in-scope tools by layer: experience (Gemini Enterprise, Workflow Builder, CX Agent Studio), build (ADK, Agents CLI, Antigravity), knowledge (Agent Search, RAG Engine, Vector Search/Agent Retrieval, MCP servers), run (Agent Runtime, Cloud Run, GKE), evaluate (Gen AI evaluation service), govern (Agent Identity, Agent Gateway, Agent Registry, Model Armor).
- **How:** A layered figure with a 'formerly' column, then a quick sort exercise. Each later topic links back to its box.

## Learning objectives
After this topic the learner can (ids become the lesson's `objectives`):
- `place-product`: Place each in-scope product on the map by what it does.
- `former-names`: Match current names to former ones (Agentspace, Agent Designer, Vertex AI Search, Agent Engine).

## Must-learn (keep nothing else but this)
1. Workflow Builder was Agent Designer; Gemini Enterprise absorbed Agentspace; Agent Search was Vertex AI Search; Agent Runtime was Agent Engine.
2. Low-code tools sit on top; ADK and the runtime sit underneath; identity, gateway and registry wrap everything.

## Key terms (glossary)
- `Gemini Enterprise`: Google's enterprise agent app and platform (formerly Agentspace).
- `Agent Platform`: Google Cloud's agent build-run-govern platform (the evolution of Vertex AI for agents).
- `Agent Runtime`: The managed runtime for deployed agents (formerly Agent Engine).
