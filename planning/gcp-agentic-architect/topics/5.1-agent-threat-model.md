# 5.1 The agent threat model

**Topic id:** `agentic-ai/agent-threat-model` · **Level:** 100 · **Difficulty:** beginner · **Est:** 15 min
**Track:** S5 Secure and govern · **Exam objective:** 5.1, 5.2 (introduction) · **Persona:** `personas/agentic-ai.md`
**Status:** plan-approved

## Why / What / How
- **Why:** Agents act, so their failures are actions: a prompt injection that sends an email is worse than one that writes a bad sentence. Every security topic answers a threat named here.
- **What:** The main agent threats (prompt injection, direct and indirect; excessive permissions; data leakage through retrieval or output; unsafe irreversible actions; unvetted tools and agents) and the four defence layers: identity, access control, runtime gateway, guardrails.
- **How:** Walk one attack (an injected instruction in a retrieved document) through an agent with no defences, then mark where each layer would stop it. Each layer points to the topic that teaches it.

## Learning objectives
After this topic the learner can (ids become the lesson's `objectives`):
- `name-threats`: Name the main agent threats with an example of each.
- `indirect-injection`: Explain indirect prompt injection through retrieved content or tool output.
- `map-defences`: Map each threat to the defence layer that addresses it.

## Must-learn (keep nothing else but this)
1. Untrusted content (documents, web pages, tool output) can carry instructions; treat it as data.
2. Least privilege limits the damage of any successful attack.
3. No single layer is enough; defend in depth.

## Key terms (glossary)
- `prompt injection`: Input crafted to override an agent's instructions.
- `indirect prompt injection`: Injection carried by content the agent retrieves or a tool returns.
- `excessive agency`: An agent holding more permissions or autonomy than its task needs.
