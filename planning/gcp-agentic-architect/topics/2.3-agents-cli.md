# 2.3 Agents CLI: the agent lifecycle from a coding agent

**Topic id:** `agentic-ai/agents-cli` · **Level:** 300 · **Difficulty:** advanced · **Est:** 20 min
**Track:** S2 Coding agents · **Exam objective:** 3.1, 2.2 · **Persona:** `personas/agentic-ai.md`
**Status:** plan-approved

## Why / What / How
- **Why:** Agents CLI lets a coding agent scaffold, evaluate, deploy and operate agents. Knowing its modes decides whether it acts on its own or waits for a person.
- **What:** Agents CLI: its bundled skills, agent mode vs human mode, and how it augments Antigravity or another coding agent across build, evaluate, deploy and govern.
- **How:** Walk the lifecycle of the 3.2 support agent through Agents CLI from a coding agent, noting which steps run in agent mode and which in human mode.

## Learning objectives
After this topic the learner can (ids become the lesson's `objectives`):
- `agents-cli-role`: Explain what Agents CLI adds to a coding agent.
- `agent-vs-human-mode`: Choose agent mode or human mode for a task.
- `cli-skills`: Use the bundled skills to run the agent lifecycle.

## Must-learn (keep nothing else but this)
1. Agents CLI packages the agent development lifecycle as skills a coding agent can use.
2. Agent mode is for automation; human mode keeps a person in control of each step.

## Key terms (glossary)
- `Agents CLI`: Google's CLI that gives coding agents the agent development lifecycle.
- `agent mode / human mode`: Agents CLI output and interaction styles for an agent caller vs a person.
