## How hashing works

A **hash function** maps a key to a bucket index in an underlying
[array](/topics/fundamentals/arrays). To store a key–value pair, we hash the key
and place the value in that bucket. To look it up, we hash again and read the
same bucket — so lookups don't scan, they jump.

## Collisions

When two different keys hash to the **same** bucket, we have a **collision**.
The simulation above lets you trigger one by inserting keys that hash to the same
slot. Real hash tables resolve collisions with strategies like{" "}
<Term>chaining</Term> or <Term>open addressing</Term>.

<Callout type="warning">
As the **load factor** (entries ÷ buckets) rises past ~0.7, collisions become
frequent. Tables resize and rehash to keep operations near O(1).
</Callout>
