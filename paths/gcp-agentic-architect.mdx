This path prepares you to design an agentic system on Google Cloud end to end and
to defend each choice: low-code or code, which model, how the agent reaches
enterprise data and tools, how agents coordinate, how the system is evaluated
before and after launch, where it runs, and how its identity, access and
guardrails are set.

It runs **subject by subject**. The core track comes first, then each exam
section from L100 to L400, so you finish one subject before starting the next.
Levels mean depth within a subject: L100 understand, L200 configure and build,
L300 design and integrate, L400 operate and harden. The core capstone comes last.

Lessons are added one at a time. Sections without a published lesson yet stay
hidden until their first lesson ships.
